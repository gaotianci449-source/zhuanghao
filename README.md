# 桩号

手机打开就能用的道路桩号工具：站在路上，显示所在路段的桩号和离中线的距离。

- 可以导入多条路段：奥维导出的 KML / KMZ，或者“桩号、北坐标、东坐标”的坐标文件（CSV、TXT、DAT）
- 实时显示桩号、左右偏距，自动判断在哪条路段上，也可以锁定一条
- 找桩号：输入 `95+300` 或 `95+300左12`，在地图上标出来，并显示距离和方位
- 底图用 Esri 卫星影像；路段只保存在各自手机的浏览器里，可以导出备份发给同事

桩号由手机定位换算，误差一般 3～5 米，只用来知道自己在哪，不能用于放样。

使用的开源组件：Leaflet（BSD-2）、Barlow Condensed 字体（OFL，见 `vendor/OFL.txt`）。
