# 桩号

手机打开就能用的道路桩号工具：站在路上，显示所在路段的桩号和离中线的距离。中文 / Français。

- 导入多条路段：奥维导出的 KML / KMZ、CAD 图（DXF / DWG）、Excel（.xlsx）、“桩号、北坐标、东坐标”的坐标文件（CSV、TXT、DAT）；选错文件会直接说明是什么文件、该怎么办
- 共享：管理员在“更多 → 数据管理”输入上传密码后，把路段和地标加密发布到本仓库的 `data/`；同事用带钥匙的链接打开一次，以后自动更新
- 拍照加水印：时间、桩号、偏距、路段、坐标、附近地标、备注
- 地标（拌合站、营地、料场等），以及 Esri 路网和地名叠加层；简单模式（大字）
- 每条路段一个颜色（中线、桩号字、20 米横线同色）；点顶部路段名可以看图例、显示/隐藏、锁定一条
- 实时显示桩号、左右偏距；找桩号：输入 `95+300` 或 `95+300左12`，在地图上标出来，并显示距离和方位
- 轨迹：边走边记录，显示距离和用时，可改名改色、导出 KML，并按闭合图形算周长、面积
- 测量：在地图上点点，或走到位置上“取当前位置”；量距离或量面积（平方米、公顷、亩），可保存、导出 KML
- 底图用 Esri 卫星影像；数据只保存在各自手机的浏览器里，可以导出备份发给同事

桩号、长度、面积都由手机定位算出，误差一般 3～5 米，只用来参考，不能用于放样。

使用的开源组件：Leaflet（BSD-2）、Barlow Condensed 字体（OFL，见 `vendor/OFL.txt`）、libredwg-web（基于 GNU LibreDWG，GPL-3.0，见 `vendor/libredwg/`，只在导入 DWG 时加载）。
